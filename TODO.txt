  - reads requesting more elements than available;
  - reads from an empty file;
  - reads after EOF;
  - `size > 1` reads that reach EOF.

  Final convention:
  - exact read of remaining content -> `OSAL_FILE_STATUS_OK`;
  - read attempt beyond available content -> `OSAL_FILE_STATUS_EOF`.


- update `stream_destroy()` contract and tests

  `stream_destroy()` now returns a `stream_status_t`.

  Final convention:
  - `s == NULL` -> `STREAM_STATUS_OK`;
  - `*s == NULL` -> `STREAM_STATUS_OK`;
  - backend close succeeds -> release stream, set `*s = NULL`, return
    `STREAM_STATUS_OK`;
  - backend close fails -> return mapped failure status, leave `*s` unchanged,
    do not release the stream.
